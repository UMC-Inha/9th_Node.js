1. Swagger 문서 작성.

   ⇒ Swagger Auto Gen을 이용해서 API 명세를 자동으로 불러와서 기본적인 OpenAPI 문서는 작성해주지만, 그 이상의 것들은 직접 해야한다…

   ⇒ Express는 데코레이션이 따로 없어서, 스프링이나 Nest처럼 자동 생성이 안된다고… 그래서 이렇게 컨트롤러단에서 스웨거 관련 설명을 직접 붙여줘야된다. (경악스럽다..)

   ⇒ 서키님이 알려주신 TSOA를 이용하는 방법도 있지만, 코드 전체를 뜯어고쳐야돼서 사용해보진 못했다..

   ![스크린샷 2025-11-23 오후 2.46.26.png](attachment:e1dd4796-5b3e-4071-a24e-4b71c7abc15f:스크린샷_2025-11-23_오후_2.46.26.png)

   ⇒ OpenAPI 자체에 저 설명도 다 때려박는 방법이 있지만, **API 문서와 실제 코드가 한 파일에 붙어 있어서 싱크 불일치 위험을 없애기 위해 컨트롤러 단에 붙여두었다.**
